Al enviar una petición POST a http://localhost:3000/registro con el siguiente JSON:
{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

El servidor responde con:
{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

Esto significa que el servidor recibió correctamente los datos enviados
en el cuerpo de la petición mediante req.body, y los devolvió organizados
en formato JSON confirmando que el registro fue procesado exitosamente.
